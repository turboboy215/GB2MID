Song table
=======================================
In most games, the song table consists of a series of 4 pointers (2 bytes, or 16-bit), 1 for each channel in ascending order. However, in at least Monkey Puncher, the each song pointer is preceded by a byte representing the number of the bank that the current song is in.

Song header
=======================================
For most games, the "header" of a song is structured as follows (if any of these values are 0, then they are unused):

1-2. Channel 1 pointer
3-4. Channel 2 pointer
5-6. Channel 3 pointer
7-8. Channel 4 pointer

For later games, the header is structured as follows:

1-2. Instrument pointers?
3-4. Channel 4 macro list pointer
5-6. Channel 1 pointer
7-8. Channel 2 pointer
9-10. Channel 3 pointer
11-12. Channel 4 pointer

Song commands
=======================================
For channel 1-3, channels use the following commands:

(First 4 bytes of song: register info)

00-4F xx = Play note (X = Length, 0/1 = Rest?)
5x = Set envelope?
6x = Set sweep?
7x yy = Set period?
8x-9x = Set instrument
Ax = Set waveform
B0 = Set channel loop position?
B1 = Start of repeat sequence (1X), mark position
B2 = End of repeat sequence
B3 = Mark position, go back to repeat start and play until B2 command, then skip to after B3 pos
B4 = Turn on slur
B5 = Turn off slur
B6 xx = Hold note (X = Length)
B7 xx xx = Jump to position
B8 = ?
B9 xx yy zz = ?
F0/BE = End of channel
FF/BF = Go to loop position

Commands B8 and B9 are only available in later games.
Channel 4, as well as channel 3 in at least 2 late games, use a simpler set of commands to play macros seen below:

00-AF? = Play macro (value from table)
B0 = Set channel loop position?
B1 = Start of loop sequence (1X), mark position
B2 = End of loop sequence
B3 = Mark position, go back to loop start and play until B2 command, then skip to after B3 pos
B9 xx yy zz = ?
F0/BE = End of channel
FF/BF = Go to loop position

When inside a macro, the following simplified set of commands is used:

00-4F xx = Play note (X = Length, 0/1 = Rest?)
5x = Set envelope?
6x = Set sweep?
7x yy = Set period?
8x-9x = Set instrument
B6 xx = Hold note (X = Length)
FF/BF = Return from macro

The macro tables, in most games, are specified from a location in code. However, in the late games, they are set per-song with pointers as seen above.

Early version (Boxxle)
=======================================
The first game to use this sound engine, Boxxle, uses an early version of the sound engine with the following commands:

CH1-3:
00-5F xx = Play note (X = Length, 0/1 = Rest?)
60-6F = Set envelope?
70-7F xx = Set envelope (v2)?
80-8F xx = Set period?
90-A1 = Set waveform
A2 = Set channel loop position?
F0 = End of channel
FF = Go to loop position

CH4 (outside macro):
00-5F xx = Play macro (value from table)
60-6F = Set envelope?
70-7F xx = Set envelope (v2)?
80-8F xx = Set period?
90-A1 = Set waveform
A2 = Set channel loop position?
F0 = End of channel
FF = Go to loop position

CH4 (inside macro):
00-5F = Play note (X = Length, 0/1 = Rest?)
60-6F = Set envelope?
70-?? xx = Set envelope (v2)?
FF = Return from macro

Compression (Jungle Wars)
=======================================
Jungle Wars uses a variant of the sound engine that stores its music data compressed in ROM and decompressed to and loaded from SRAM. For this, the following algorithm is used:
First 2 bytes = Total compressed size
Next 8 bytes = Uncompressed, copy
Next, check if the following byte is E0 or more

If less than E0, then copy uncompressed byte
Otherwise, ...
 - SWAP value and get lowest bit (0 or 1 resulting value = High value of an address)
 - Low value of an address = next byte
 - Add to start of compressed data to get absolute value
 - Lower 4 bits of original byte = Bytes to copy
 - Repeat copy until all bytes specified are copied:
   - If less than E0, then copy byte
   - Otherwise, "meta" version of E0 event

Additionally, for the reason that E0 and above represent references to previous data, commands F0 and FF have been moved to BE and BF respectively.
