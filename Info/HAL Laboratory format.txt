Song pointer table
=======================================
The song pointer table is comprised of 16-bit pointers to each song as well as sound effects.

Song header
=======================================
The header for each song is structured as follows:

1 byte = How many channels are active in a song/sound effect
Then repeat for each available channel:
2 bytes (for each active channel) = 16-bit pointer to start of sequence
1 byte = Binary mask representing channel number
	00 = Channel 1
	04 = Channel 2
	10 = Channel 3
	0C = Channel 4

For Ghostbusters II and Trax, which use a different version of the driver, the header for each song is instead as follows:

1 byte = Binary mask representing channel number
	00 = Channel 1 (music)
	01 = Channel 2 (music)
        02 = Channel 3 (music)
        03 = Channel 4 (music)
        04 = Channel 1 (sound effects)
        05 = Channel 2 (sound effects)
        06 = Channel 3 (sound effects)
        07 = Channel 4 (sound effects)
2 bytes (for each active channel) = 16-bit pointer to start of sequence
(Repeat until the following byte:)
FF = End of channel header

Sequence format
=======================================
Sequences are comprised of the following commands:
00-DF = Play note/length:
  xxxyyyyy = Play note (X = length from table (each 6 bytes), Y = note (-15 to 15 from base note value, signed delta)
  11xxxxxx yyyyyyyy = Play note with explicit length (X = note (-15 to 15 from base note value, signed delta), Y = length)
  xxx10000 = Rest (X = Length in frames)
E1 xx = Sync sound (X = Time)
E2 xx xx = Set period directly (X = Period value)
E3 xx = Set tuning (X = Value, signed)
E4-EF = (Invalid)
F0 xx = Set note volume (absolute) (X = Value - clamped to 15)
F1 xx = Set note value (add) (X = Value - clamped to 15)
F2 xx = Set channel note length table (X = List number)
F3 xx = Hold note by amount (X = Length in frames)
F4 xx = Set note duration/gate (X = Length, 0 = endless)
F5 xx = Set base note (X = Note number)
F6 xyyyyyyy = Set instrument (X = Run the attack envelope once now instead of at every note, Y = Instrument number)
F7 xx = Set tuning table entry (X = Table entry number)
F8 xx xx = Jump to position (X = Pointer)
F9 = (Invalid)
FA xx xx = Go to macro (X = Pointer) (nested macros supported)
FB = Return from macro
FC xx = Start of repeat section (X = Number of times) (nested repeats supported)
FD = End of repeat
FE ------xx = Set panning (X = Left, 1 = Right)
FF = End of channel

Ghostbusters II and Trax use different commands:
00-7B = Play note:
	xxxxyyyy (X = Octave, Y = Note)
7C = Rest
80-BF = Change note length (Uses only one big note table as opposed to multiple switched 6-byte ones)
C0-EF = (Invalid)       
F0 xx = Set envelope (X = Entry from table)
F1 xx = Set duty (X = Duty (OR $3F))    
F2 xx = Attenuate (X = Value subtracted from every envelope volume)
F3 xx = Set transpose (X = Value, signed)
F4 xx = Start of repeat section (X = Times)
F5 = End of repeat section
F6 xx xx = Play macro at position (X = Pointer) (one level only)
F7 = Return from macro
F8 xx = Set sweep (X = Value ((XOR 8) & $7F))
F9 = Sweep off
FA = (Invalid)
FB xx xx = Go to macro (X = Pointer)
FC = (No effect)
FD xx = Play sound effect
FE = (Invalid)
FF = End song without loop

Instruments
=======================================
Instruments are accessed from two pointers: an attack envelope started at every note, and a release envelope started when the release countdown expires.
The envelopes are structured usinb the following commands:
000wwwww = wait (w)
001Wssss = period += s (signed); W = then wait 1 frame
010Wvvvv = v = envelope volume (low nibble of track volume); W = then wait 1 frame
011Wssss = s = Add to envelope volume; W = then wait 1 frame
100Wxxxx = duty (CH1/2/4, NRx1 bits 6–7) or wave number
F0 xx = register 0 of the channel (NR10 sweep, NR30)
F8 xx xx = Jump to position (X = Pointer)
FA xx xx = Go to macro (X = Pointer)
FB = Return from macro
FC xx = Start of repeat section (X = Times) (nested repeats supported)
FD = End of repeat
FF = End of track envelope
