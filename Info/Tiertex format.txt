Note that the following tables are described in the typical order that they appear in the sound data.

Frequency table
=======================================
A standard frequency table is found with the following instructions:

ld hl, note_table
add a
add l
ld l, a
adc h
sub l

In hex, this equates to:
21 F7 ?? ?? 85 6F 8C 95

Song table
=======================================
The song table is a series of four 16-bit pointers denoting the location of each song's tracks, one for each channel.

Song control
=======================================
Each song has a "control" list, each consisting of four bytes each. The format represents as follows:
1. Volume
2. Panning
3. Sounds on
4. Unused (marked as "UNKOWN (Future development" in source code)

These always seem to be set to $FF, $FF, $8F, $00.

Channel 4 instruments
=======================================
Each channel 4 (noise) instrument is comprised of 3-byte definitions as follows:
1. Frequency
2. Envelope
3. Maximum time (00 = shortest, 63 = longest, bit 6 = "continuous" if set)

Channel 1 and 2 instruments
=======================================
Channel 1 and 2 (square) instruments are variable length. They are structured as follows:
1. Number of sections for vibrato
2-3. Frequency (used for SFX)
4. Priority (1 = Music, -1 = SFX)
5 x 1. Vibrato sections

Channel 3 instruments
=======================================
Like channel 1/2, channel 3 (wave) instruments are variable length, and are similar in format. They are structured as follows:
1. Number of sections for vibrato
2-17. Waveform
18 x 1. Vibrato sections

Song channel track commands
=======================================
Tracks for each channel of a song are comprised of the following commands:
FF = Restart channel
FE = End of channel
FD = End of repeat section
FC xx = Repeat the following section (X = Times) (1 level only)
F9 xx yy zz zz = Go to macro (X = Number of times, Y = Transpose (signed), Z = Pointer)
F8 = End of macro
80-BF = Set instrument
00-7F xx = Play note (X = Length), 00 = Rest
