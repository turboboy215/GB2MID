There are two different Capcom sound engines; the second version is either different than the first or heavily reprogrammed. Version 1 is only used in DuckTales (1), and is based on the second version of the NES engine from 1987, whereas version 2, first used in Gargoyle's Quest (1) and Capcom Quiz, is based on the third version of the NES engine from 1990. This sound engine stopped being used for a long time after Who Framed Roger Rabbit? in 1991, presumably due to Capcom working with additional outside development teams having their own sound engines, before being used again in late 1999 in Magical Tetris Challenge and Hamster Club, and was used in several other Capcom games including Mega Man Xtreme 1 and 2.

Version 1 (DuckTales)
===========================================================================

Song table
=======================================
The song table consists of 16-bit entries for each song, music only.

Song header
=======================================
The header for each song is 11 bytes, structured as follows:
1. Tempo
2. "Half" flag (if not 0, then every note length is half length)
3-4. Channel 1 pointer
5-6. Channel 2 pointer
7-8. Channel 3 pointer
9-10. Channel 4 pointer
11-12. Vibrato table

Song commands
=======================================
Each channel of a song uses the following commands:
00 xx = (No effect)
01 xx = (No effect)
02 xx = Set duty
03 xx = Set volume (NRx2 bits 7-4)
04 xx yy yy = Repeat section - jump to position (X = Number of times, Y = Pointer)
05 xx = Set base note
06 = Next note is "dotted" (1.5 length)
07 xx = Set envelope direction/sweep pace (NRx2 bits 3-0)
08 xx = Set vibrato (value from table, period +1 every 3 frames; 0 = no vibrato)
09 = End of song
0A-0F xx = (No effect)
10-20 = End tick without a note (rest)
21-2F = Tie next (command - 1F) notes together
30 = Triplet - next note uses the triplet lengths
31-FF = Play note:
	yyyxxxxx (X = Note, Y = Length)
(Lengths for notes:
	1, 3, 6, 12, 24, 48, 96 (normal)
	1, 2, 4, 8, 16, 32, 64 (triplet))

Sound effects table
=======================================
Sound effects are stored in a separate table. Like music, this table is comprised of 16-bit entries to each sound effect.

Sound effects
=======================================
Sound effects use a stream format. The streams are structured as follows:

Byte 1: Channel mask (bits 0-3)
Byte 2:
80-87 xx (1hhh hhhh xxxx xxxx) = Play note for period (H = Note, X = Length)
88-FF xx = Replay the previous period (X = (Unused))
00 xx = Wait frames (X = Number of frames)
01 xx/07 xx = Signed pitch/period change per frame before next event
02 xx = Set duty (NRx1) for following notes
03 xx = Set duty (NRx2) for following notes
04 xx yy yy = Repeat section - jump to position (X = Number of times, Y = Pointer)
05 xx = Add vibrato value every 3 frames
06 = End of effect

Sound effects priority
=======================================
Sound effects are loaded using a "priority" system which are values loaded from a table.



Version 2
===========================================================================
Note that pointers are stored as BIG-ENDIAN!

Song table
=======================================
The song table consists of 16-bit entries for both songs and sound effects.  If an entry in the table starts with value 00, it is music; otherwise, it is a sound effect.

Song header
=======================================
The header of a song is structured as follows:
1. Byte 00
2-3. Channel 1 pointer
4-5. Channel 2 pointer
6-7. Channel 3 pointer
8-9. Channel 4 pointer

Song commands
=======================================
Each channel of a song uses the following commands:
00 = Triplet - Toggle triplet lengths (see below)
01 = Connect - Toggle - a note after a connected one isn't re-triggered
02 = Dotted - Next note is 1.5x length
03 = Toggle - +2 octaves up
04 xyzabccc = Set channel flags:
	x = Connect (this note)
	y = Connect
	z = Triplet flag
	a = Dotted flag
	b = +2 octaves up flag
	c = Octave
05 xx = Set tempo (8.8 ticks per frame; default = $0199 (1.6))
06 xx = Set note duration/gate
07 xx = Set volume (0-15)
08 xx = Set instrument
09 xx = Set octave (0-7)
0A xx = Transpose (global)
0B xx = Transpose (local)
0C xx = Set tuning
0D xx = Pitch slide
0E xx yy yy = Repeat section (1) (X = Number of times, Y = Pointer)
0F xx yy yy = Repeat section (2) (X = Number of times, Y = Pointer)
10 xx yy yy = Repeat section (3) (X = Number of times, Y = Pointer)
11 xx yy yy = Repeat section (4) (X = Number of times, Y = Pointer)
12 xyzabccc dd dd = Set flags and jump to position (1) (X-C = Flags, same as 04, D = Pointer)
13 xyzabccc dd dd = Set flags and jump to position (2) (X-C = Flags, same as 04, D = Pointer)
14 xyzabccc dd dd = Set flags and jump to position (3) (X-C = Flags, same as 04, D = Pointer)
15 xyzabccc dd dd = Set flags and jump to position (4) (X-C = Flags, same as 04, D = Pointer)
16 xx xx = Jump to position (X = Pointer)
17 = End of channel
18 xx = Set duty
19 xx = Set panning (11 = L/R, 10 = L, 01 = R)
1A-1F = (Invalid)
20-FF = Play note OR rest (length = bits 7-5 (1-7 = 3, 6, 12, 24, 48, 96, 192), note = bits 4-0, 0 = rest)

Instruments
=======================================
Instruments are structured as follows:
1. Attack
2. Decay
3. Sustain
4. Release
5. Vibrato speed
6. Vibrato septh
7. Duty
8. Waveform

Sound effects
=======================================
Sound effects are structured as follows:
1. Header flag: Bit 7 = Loop flag, bit 6-0 = Priority (1-127)
For each segment:
1. NR51 bits (0 = end)
2. Flags = Bit 2 = transpose, bit 1 = hold, bit 0 = loop
(If not end)
3. Loop count (0 = endless)
4-5. Loop pointer
6. Hold
7. Transpose
8. Frame duration
9. Frame channel mask
(Then, for each note/command:)
10. Flags for following command: bit 0 = instrument, bit 1 = duty, bit 2 = volume, bit 3 = slide, bit 4 = tuning (in order)
11. Note with command (00 = key off, FF = hold)
