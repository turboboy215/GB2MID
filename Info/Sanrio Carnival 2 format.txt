Song table
=======================================
Each song in the song table is comprised of a series of 4 16-bit pointers to each channel of a song - 8 bytes total, with an unused entry being 00xx.

Song commands
=======================================
Each channel of a song uses the following commands:
00-7F (xx (yz aa)) = Play note (X = Note (00 = Rest), Other bytes used when repeat counter has run out: Y = Length (index to note table), Z = Repeat counter (same length))
80 xx xx = Set waveform (X = Pointer)
81 xx = Set master volume (X = Value)
82 xx = Set panning (X = Value)
83 xx = Set NR10 (X = Value)
84 xx = Set NR11 (X = Value)
85 xx = Set NR21 (X = Value)
86 xx = Set NR31 (X = Value)
87 xx = Set NR41 (X = Value)
88 xx = Set channel 1 envelope sequence (X = low byte of 6Dxx pointer)
89 xx = Set channel 2 envelope sequence (X = low byte of 6Dxx pointer)
8A xx = Set channel 3 envelope sequence (X = low byte of 6Dxx pointer)
8B xx = Set channel 4 envelope sequence (X = low byte of 6Dxx pointer)
8C xx = Set channel 1 vibrato sequence (X = low byte of 6Dxx pointer)
8D xx = Set channel 2 vibrato sequence (X = low byte of 6Dxx pointer)
8E xx = Set channel 3 vibrato sequence (X = low byte of 6Dxx pointer)
8F xx xx = Set note length table (X = Pointer)
90-92 = (Invalid)
93 xx xx = Jump to position (X = Pointer)
94 xx xx = Go to macro on channel 1 (multiple levels?)
95 xx xx = Go to macro on channel 2 (multiple levels?)
96 xx xx = Go to macro on channel 3 (multiple levels?)
97 xx xx = Go to macro on channel 4 (multiple levels?)
98 = Return from macro on channel 1
99 = Return from macro on channel 2
9A = Return from macro on channel 3
9B = Return from macro on channel 4
9C = End of channel 1
9D = End of channel 2
9E = End of channel 3
9F = End of channel 4

Macros
=======================================
Macros are used for changing the envelope or vibrato of a channel. Each macro is structured with 2-byte rows which represent the number of frames used and then the parameter. Each macro runs into each other, as they have no proper terminator value.

Sound effects
=======================================
Sound effects are byte-code streams with the following commands:
00-3F = Set register writes (bits 0-2 = NRx0-2, bit 3 = NRx3-4)
40-5F = Hold/resume the music
60-6F = End = silence the channels in the mask
70-7F = The channels this effect takes
80-FF = Wait number of frames ($80 = 128)
